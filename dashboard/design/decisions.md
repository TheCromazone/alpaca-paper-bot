# Cinematic overhaul — decisions

Start-questionnaire (autonomous session; answers inferred from the request + existing repo):
- Mode: elevate existing site (screenshot-equivalent: the live Cromaz dashboard itself)
- Image placeholders: none — every surface is live data
- Niche: LLM-driven paper-trading terminal ("is the bot beating the S&P?")
- Pages: Overview (primary scene), Holdings / Trade Journal / Market Wire / Insider Desk (inherit global atmosphere this pass)

## Director + film language
**Michael Mann — Heat / Collateral (night-city precision), tempered by Fincher restraint.**
Translation: an ops room at 3am. One luminous signal color (the brand emerald) against
obsidian; chrome speculars; machine telemetry presented with surveillance-grade precision.
Motion is slow, deliberate, never decorative for its own sake.

Research constraint: web research unavailable mid-build; language derived from the existing
Cromaz brand system (obsidian + chrome + emerald, Cinzel monumental display) which already
encodes this direction. Marked as an inference pass, not a fresh research pass.

## Previous-work audit (the current dashboard IS the prior output)
Recurring traits: uniform full-width stacked strips separated by identical rule-tops;
a row of four equal stat cards; a single entrance style (everything just appears);
identical section-head weight everywhere; chart floats in the page instead of owning it.

## Shell-ban list
1. No uniform stacked strips with identical rule-top separators as the page's only rhythm.
2. No rows of N identical stat cards as a hero element.
3. No single-entrance-type page.
4. No section that would survive unchanged as a generic 3-col product grid.

## Primary composition family
**Command bridge** — one monumental full-bleed stage (the equity curve as the film's
one irreplaceable shot), then an asymmetric telemetry corridor, then ledger scenes.
